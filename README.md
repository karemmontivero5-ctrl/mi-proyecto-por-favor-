# mi-proyecto-por-favor-

Proyecto de prueba, listo para trabajar con **VS Code + Claude + ChatGPT** desde el navegador.
No hace falta instalar nada en la notebook.

## Cómo abrirlo

[![Abrir en GitHub Codespaces](https://github.com/codespaces/badge.svg)](https://codespaces.new/karemmontivero5-ctrl/mi-proyecto-por-favor-)

1. Tocá el botón de arriba (o en GitHub: **Code → Codespaces → Create codespace on main**).
2. Esperá 1–2 minutos: se abre VS Code en el navegador con todo instalado.
3. En la barra lateral vas a ver los paneles de **Claude Code** y de **Codex (ChatGPT)**.
   La primera vez, iniciá sesión en cada uno con tu cuenta.
4. Pedile cosas a cualquiera de los dos: trabajan sobre los mismos archivos de esta carpeta.

## Guardar los cambios

Icono de **Control de código fuente** (o `Ctrl+Shift+G`) → escribí un mensaje → **Confirmar** → **Sincronizar**.
Así todo queda guardado en GitHub.

## Importante: apagá el Codespace al terminar

GitHub da unas horas gratis por mes. Para no gastarlas de más:
**github.com/codespaces** → los tres puntitos al lado de tu Codespace → **Stop codespace**.
(Igual se apaga solo después de un rato sin uso.)
